🛡️ Resilience & Fallbacks

  • Cloud DB Fallback: If Neon connection has latency or credential delay, Prisma service uses local memory seed so demo never stalls.
  • WebSocket Graceful Degradation: If socket drops, client automatically queries REST endpoints without broken states.
  • 2-Hour Session Expiry: Clean JWT/session management with automatic validation.
