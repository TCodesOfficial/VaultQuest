Your Universal Gaming Identity, Everywhere

🚀 Core User Journey

PHASE 1
3-Slide Onboarding

Relatable story: The pain of lost passwords & stranded saves → VaultQuest solution → Quick 2-step UI highlight tour.

PHASE 2
Dashboard Hub

Responsive game grid (4-5 desktop, 2 mobile) showing cover thumbnails, gamertags, and multi-platform icons.

PHASE 3
Cross-Platform Analytics

Side-by-side progression drawer comparing Mobile vs. PC vs. Console levels and achievements.

PHASE 4
Credentials Vault

Tap "Check Login Details" to immediately view & copy username/password for any game platform.

🔍 Feature & Acceptance Explorer

Goal: Emotionally connect with the player's pain before delivering the solution.

  • ✓ 3 narrative slides covering pain, solution, and mechanism.
  • ✓ Interactive guided tour highlighting 3 core UI zones.
  • ✓ "Skip Tour" button lets power users jump straight into their library.

Goal: Visually striking game cards with zero spreadsheet feel.

  • ✓ Card grid adapts smoothly: 4-5 on desktop, 2-3 on tablet, 2 on mobile.
  • ✓ High-res game artwork thumbnails, gamertags, platform badges, and levels.
  • ✓ First-use banner suggesting popular titles to add with one click.

Goal: The "oh that's cool" moment: seeing progress across platforms side-by-side.

  • ✓ Tapping a card opens the Game Detail modal with full cover art.
  • ✓ Side-by-side analytics compares Mobile Level vs. PC Level and achievements.

Goal: Instant access to game accounts when switching consoles or devices.

  • ✓ Prominent primary action button: "Check Login Details".
  • ✓ Stored username and password revealed with mask/unmask toggle & one-click copy.

Goal: Gamer aesthetic with flexible viewing preference.

  • ✓ Dark mode (deep slate navy + neon glow) as default.
  • ✓ Light mode (clean, high-contrast, modern) toggle in top navigation.
